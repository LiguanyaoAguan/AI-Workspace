# AI 工坊（AI Workspace）

一个以 Markdown 与少量 Python 脚本构成的**个人 AI 文件管理系统**。
它不依赖数据库、服务器或第三方服务，整个系统就是一组目录、规则文档和 5 个脚本。

> 设计目标：让 AI Agent 能可靠地"找到项目、恢复上下文、安全改文件、维护索引"，而人始终掌握最终决定权。

---

## 它是什么 / 不是什么

**是**：
- 一套约定好的目录结构与规则（七大目录 + 项目三件套）。
- 一套确定性的工具：项目创建、进度同步、资料索引、快照/恢复、工作区体检。
- 一套安全写入流程：`begin → 编辑 → end → audit`，可追溯、可回滚。

**不是**：
- 不是笔记软件，不带界面。
- 不是向量数据库或语义检索系统。
- 不包含任何示例项目、个人知识、历史快照或日志。

---

## 核心特性

| 能力 | 实现方式 |
| --- | --- |
| 项目登记与路由 | `01_项目库/项目总表.md`（8 列，含关键词） |
| 跨对话恢复 | 每个项目的 `README.md` + `任务与进度.md` + `交接记录.md` |
| 单一真相 | `任务与进度.md` 是权威，总表摘要由工具派生 |
| 知识/技能索引 | `02_知识库/索引.md`、`03_技能库/索引.md` |
| 写前保护 | `快照.py begin` 生成唯一操作编号与写前快照 |
| 写后校验 | `快照.py end` 校验并推进基线 |
| 严格审计 | `快照.py audit --strict`，未结束操作或未受保护修改都会失败 |
| 恢复 | `快照.py restore <编号>`，默认只预览，需 `--confirm` |
| 体检 | `检查工作区.py` 汇总结构、总表、三件套、索引、进度、审计 |

## 目录结构

```
AI-Workspace/
├── AGENTS.md                 # 工作区规则（行为约定，非系统强制）
├── 新对话开场指令.md          # 新会话可直接粘贴的开场提示
├── 00_前台/                   # 想法、立项讨论、灵感箱
├── 01_项目库/                 # 正式项目 + 项目总表
├── 02_知识库/                 # 可复用知识 + 索引
├── 03_技能库/                 # 可调用流程/脚本说明 + 索引
├── 04_素材库/                 # 原始素材
├── 05_归档/                   # 经批准归档
├── 06_工具箱/                 # 5 个脚本、模板、说明
└── .ai-workspace/            # 运行时数据（基线、快照、日志），默认不纳入版本控制
```

## 快速开始

```sh
cd "你的 AI 工坊 文件夹"

# 1. 建立安全审计基线
python3 06_工具箱/快照.py init

# 2. 体检（应全部通过）
python3 06_工具箱/检查工作区.py

# 3. 创建一个项目（关键词会同时写入 README 与总表）
python3 06_工具箱/新建项目.py "我的第一个项目" --keywords "示例, 测试" --confirm

# 4. 同步总表摘要
python3 06_工具箱/进度同步.py sync --confirm
```

详细步骤见 [INSTALL.md](INSTALL.md)。

## 用自然语言使用

把下面这些话直接对 AI Agent 说即可（它会按 `AGENTS.md` 的规则操作）：

- "帮我继续上次没做完的工作。"
- "帮我创建一个 AI 视频制作项目，并整理接下来要做的任务。"
- "把这份资料整理好，放到合适的位置。"
- "看看工作区有没有重复资料，告诉我哪些可以清理。"
- "我现在还有哪些项目没做完？接下来应该先做什么？"
- "把这次的经验整理成以后能复用的知识。"

写入类请求会先快照，再修改，最后审计；失败会停下并报告。

## 安全模型（重要）

1. 修改已有文件前必须 `begin`，写完 `end`，阶段结束 `audit --strict`。
2. 删除用 `快照.py delete`，不直接 `rm`；移动/重命名用 `begin --kind move/rename`。
3. 备份与基线在 `.ai-workspace/`：`backup/`、`state.json`、`ops/`、`changes.log`。
4. **边界**：`AGENTS.md` 是行为约定，不是系统级强制；绕过工具的直接编辑只能靠 `audit` 事后发现。
5. 系统不保存任何密码、Token、Cookie；也不应把这类内容写进工作区。

## 环境要求

- Python 3.8+（只用标准库，无第三方依赖）。
- macOS / Linux / Android(Termux) 均可；路径含空格时命令加引号。
- 不需要 Git；如使用 Git，建议只跟踪文档与脚本，忽略 `.ai-workspace/` 运行时数据。
