# 知识库索引

本索引收录 `02_知识库/` 下的全部资料。新增、改名、删除文件后必须同步索引：

```sh
python3 06_工具箱/资料索引.py add 02_知识库/文件名.md --title "标题" --scene "什么时候该用这份资料" --keywords "词1,词2" --summary "一句话摘要"
python3 06_工具箱/资料索引.py remove 02_知识库/文件名.md
python3 06_工具箱/资料索引.py check
```

「适用场景」用自然语言写清楚用途，检索时按语义匹配，而不是只对关键词。
