# Git 使用说明（可选）

Git 仅用于单个正式项目。首次 `git init`、添加文件或提交前，先列出命令和拟纳入文件，等待用户单独批准。不得在 AI 工坊根目录初始化仓库，除非用户明确决定。

## 提交前检查

1. 进入项目目录并检查 `git status --short`。
2. 查看变更内容，确认没有 API Key、Token、密码、Cookie、个人隐私、缓存、临时输出或不应纳入的大型素材。
3. 先配置项目级忽略规则；不要假定全局配置已经足够。
4. 仅在用户批准后暂存明确文件并提交，提交信息说明变更目的。

## 建议排除

`.env`、凭据和密钥文件、缓存目录、`__pycache__/`、临时文件、可再生成构建产物、未经确认的大型视频/音频/模型文件。需要追踪的素材应先讨论体积、来源与许可。

## 查看与恢复

查看用 `git status`、`git diff`、`git log --oneline`。恢复前先查看目标提交和工作区状态，说明将影响的文件并取得批准。禁止自动执行 `reset --hard`、`clean`、强制覆盖、重写历史或删除分支。Android 共享存储上的 Git 文件权限/大小写/提交兼容性需先在隔离位置验证。
